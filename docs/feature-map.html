Office

Your own desktop workspace: every project, agent, repo, branch, worktree, note and notification in one window, on top of the brain.

The nine areas

1
Home
M1
Your morning screen
  • What is waiting on you, across all projects
  • Live agents: running, needs you, done
  • Yesterday's brief per project (M2)
2
Projects
M1
Every project in one place
  • Branch, changes, PRs and CI at a glance
  • Todos and notes straight from the brain
  • Ctrl+K to jump to any project, branch or session
3
Agents
M2
Claude Code, Codex and more, side by side
  • The real tools in embedded terminals
  • Status for each: working, needs you, done
  • Closing a session saves what is left, then archives it
4
Git
M1 to M3
Every repo, branch and worktree
  • Sync all; conflicts shown, never auto-merged
  • A worktree per task, with an agent inside
  • Diff review, with comments sent back to the agent
5
Orchestrator
M4
Set who does what once
  • Roles: planner, builder, reviewer, artist
  • Pipelines with your approval between steps
  • Task board, and fan-out to several agents
6
Brain
M2
Your memory, one question away
  • Ask the brain anything
  • Quick notes, filed and committed
  • Tick todos right from Office
7
Inbox
M1 and up
Every notification in one place
  • Agents, git, CI and automations
  • Urgent ones as desktop alerts
  • Mute, quiet hours, phone pings later
8
Setup
M1
Install on any PC in minutes
  • Clone the brain, pick the projects folder
  • Connect Claude, Codex and others with your plans
  • See every skill, MCP and hook you have
9
Explore
M2
Think freely, then spawn a project
  • A general chat not tied to any project
  • "Make this a project": folder, git, GitHub, brain notes
  • Opens a session there with the exploration as its brief

How it fits together

Office (you build this)Projects, roles and pipelines, the brain chat, your setup, the inbox
launches and watches
Agent tools (already exist)Claude Code, Codex, any other command-line agent, with your own logins
work on
