# My brain

Project and shared notes in plain Markdown inside one Git repo.

- `AGENTS.md`: the rules agents follow when they work with these notes.
- `_index.md` links to the project routers and shared notes.
- `Projects/<Name>/_index.md` lists the notes for each project.
- `General/` holds notes from chats without a project.
- `Shared/OwnerProfile.md` holds working preferences across projects.
- `Office/workspace.json`: the list of projects, roles and pipelines Office uses.
