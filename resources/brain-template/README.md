# My brain

The notes for my projects: what each one is, what is left to do, what waits on me. Office reads
and writes here, and so can any coding agent. Everything is plain Markdown in one git repo.

- `AGENTS.md`: the rules agents follow when they work with these notes.
- `Projects/<Name>/Overview.md`: what a project is, its stack, where its code lives.
- `Projects/<Name>/OpenItems.md`: what is left to do, and a "Waiting on you" section.
- `Office/workspace.json`: the list of projects, roles and pipelines Office uses.
