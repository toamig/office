# Agent rules for this brain

These notes belong to the owner. Follow these rules whenever you read or write them.

1. **Start with the routers.** Read `_index.md`, the project's `_index.md` and the one note that
   answers your question. Work in your own project's notes. A project with `private: true`
   in its `brain.json` is readable only by that project's sessions.
2. **File notes by topic.** Use Decisions for choices, OpenItems for remaining work, and the
   project router to find the files for contracts, design, audience, references and lessons.
3. **Keep "Waiting on you" in its format.** One line per item under the `## Waiting on you`
   heading of the project's `OpenItems.md`: `- [ ] YYYY-MM-DD what the owner has to decide or do`.
   Remove the line when it is done.
4. **Say a fact once.** If another note already owns a fact, link to that note instead of
   restating it.
5. Give notes a type, domain, summary, questions they answer, tags and authority in YAML
   frontmatter. Link by path from the brain root.
6. Use Validate and Reindex in Office's Brain view. Leave generated router tables to Office.
7. Files are UTF-8 without BOM, with LF line endings.
