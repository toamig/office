# Agent rules for this brain

These notes belong to the owner. Follow these rules whenever you read or write them.

1. **Read the project's Overview first.** `Projects/<Name>/Overview.md` says what the project is,
   what it is built on and where its code lives.
2. **Record decisions and open items where they belong.** A decision goes in the project's
   Overview (or a note it links to); something left to do goes in the project's `OpenItems.md`.
3. **Keep "Waiting on you" in its format.** One line per item under the `## Waiting on you`
   heading of the project's `OpenItems.md`: `- YYYY-MM-DD: what the owner has to decide or do`.
   Remove the line when it is done.
4. **Say a fact once.** If another note already owns a fact, link to that note instead of
   restating it.
5. Files are UTF-8 without BOM, with LF line endings.
