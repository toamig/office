# Office

One desktop workspace for every project, agent session, repo and note.

Office runs Claude Code, Codex and other command-line coding agents side by side in real
terminals, manages git across every repo, branch and worktree, keeps each project's todos and
notes from a git-backed knowledge vault, routes work through roles (who plans, who builds, who
reviews), and gathers every notification into one inbox.

**Status:** early design. Nothing is built yet.
**Features:** see [docs/feature-map.html](docs/feature-map.html) for the areas and the build order.
**Stack:** Electron, TypeScript and React.

Office does not ship models or hold credentials. It drives the agent tools you already have
installed and logged in with your own plans.
